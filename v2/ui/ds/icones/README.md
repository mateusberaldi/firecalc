# Icones

Conjunto único da interface: Lucide 0.460.0 (licença ISC), traço 2, grade de 24, desenhado em `currentColor`. Na tela, 16 px (`fc-ic`) e 20 px (`fc-ic--g`). Como `<img>` a tinta não muda: a tinta destes arquivos é preta; no código, insira o SVG em linha para herdar a cor.

| Arquivo | Uso |
|---|---|
| `circle-check` | Atende, etapa concluída, notificação de sucesso |
| `circle-x` | Não atende, erro de campo |
| `triangle-alert` | A conferir, ressalva, dado faltando |
| `info` | Aviso informativo, padrão da norma |
| `circle-dashed` | Sem dados |
| `check` | Marcador de etapa concluída |
| `x` | Fechar janela |
| `chevron-down` | Seta do seletor |
| `search` | Busca rápida |
| `undo-2`, `redo-2` | Desfazer, refazer |
| `moon`, `sun` | Trocar tema |
| `download` | Baixar projeto |
| `folder-open` | Abrir projeto |
| `file-plus`, `plus` | Novo projeto |
| `arrow-left`, `arrow-right` | Voltar, próximo |
| `chart-column` | Estatísticas |
| `database` | Cadastros |
| `settings` | Configurações |
| `circle-help` | Ajuda |
| `droplets` | Campo hidráulico na busca |
| `gauge` | Bomba e pressão na busca |
| `list-checks` | Verificações |
| `file-text` | Relatório e glossário |
| `waypoints` | Rede |
| `house` | Início |
| `lock` | Cadastro só para consulta |
| `menu` | Abrir a barra lateral no celular |

## Acrescentados para a interface (L11 da FC-042)

Mesmo Lucide 0.460.0 (ISC), mesma grade e mesmo traço. O design system não traz estes; o script de sincronização do repositório de desenvolvimento os escreve.

|---|---|
